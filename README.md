## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
# Clone the repository
git clone <your-repo-url>
cd "Miss Lyn's Wings"

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
